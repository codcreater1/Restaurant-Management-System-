Restaurant Management System 🍽️

Restaurant Management System is a simple C++ console application to manage a restaurant. It allows you to manage menu items, take orders, track tables, and calculate daily revenue.

Features

Menu Management: Add and view menu items with name, category, and price.

Order Management: Take orders for tables, view orders, and close tables.

Table Management: Track table occupancy and orders.

Revenue Tracking: Calculate total revenue per day.

Console-Based: Simple menu-driven interface.

How to Use

Clone the repository or download the source code.

Compile the program using a C++ compiler:

g++ -o Restaurant Restaurant.cpp


Run the program:

./Restaurant


Use the on-screen menu to manage the restaurant:

Add menu items

Show menu

Take orders for tables

Show table orders

Close tables and calculate total

View daily revenue
